# [0.153.3-agentcodi.1] - 2026-09-10

## Codex Termux 0.153.3-agentcodi.1 â Android sandbox backend

This release introduces a native Android sandbox backend for Termux and
applications embedding the Codex app-server.

Android no longer depends on Landlock to provide the filesystem sandbox.
`codex-linux-sandbox` now supervises commands using seccomp-BPF and ptrace,
intercepts filesystem operations and evaluates them against the configured
Codex filesystem policy.

The backend fails closed if supervision cannot be established and uses
`PTRACE_O_EXITKILL` so tracees cannot continue without their supervisor.

Landlock remains available only as optional additional hardening. Its complete
setup is probed in a disposable child first, preventing Android seccomp
policies that reject Landlock syscalls with `SIGSYS` from terminating the
actual sandboxed command.

Kernels without `PTRACE_O_TRACESECCOMP` use a slower ptrace fallback that
monitors every syscall while preserving the same enforcement model.

Dedicated regression tests exercise the Android sandbox and inherited syscall
restrictions before the Android ARM64 build is allowed to proceed.

## Compatibility

- Android 10+ / API 29+
- ARM64
- Package: `@mmmbuto/codex-cli-termux`
- Upstream base: OpenAI Codex `rust-v0.153.2`
