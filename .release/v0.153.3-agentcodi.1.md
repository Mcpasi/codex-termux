# [0.153.3-agentcodi.1] - 2026-09-06

## Codex Termux 0.153.3-agentcodi.1 — agentcodi build line

This release republishes the `0.153.3` tree on the `agentcodi` build line. It
carries no functional change over `0.153.3`: the version string is the only
deliberate difference, so the npm artifact and the Cargo workspace both report
`0.153.3-agentcodi.1` and `codex --version` reports the same string.

The update check treats an `agentcodi` prerelease as its own patch level, in the
TUI and in `codex doctor` alike. A build on this line is therefore not reported
as out of date against the published `0.153.3`, while the next upstream patch
still surfaces normally.

## Compatibility

- The package remains `@mmmbuto/codex-cli-termux` for Android ARM64
  (Android 10+ / API 29+).
- The upstream base remains OpenAI Codex `rust-v0.153.2`.
