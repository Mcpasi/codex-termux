# [0.153.3-agentcodi.2] - 2026-09-10

This release adds opt-in `just_in_time_approvals` for commands, file patches
and non-empty terminal input. Each action waits for a human Allow/Deny decision
before execution, including after earlier session or rule approvals.

Existing app-server approval RPCs carry these decisions for embedding clients
such as AGENTCODI. Just-in-time approvals preserve the selected filesystem
sandbox profile, including full access.

Upstream base: OpenAI Codex `rust-v0.153.2`.
